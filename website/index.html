01THE SHORT VERSION

Data science feels less intimidating when you can see each step.

DataForge is a Python toolkit with an optional local dashboard. Bring a CSV or Excel file, learn what’s inside, try a model, and take your work with you as an editable Jupyter notebook.

You choose what to explore and what to predict. DataForge checks the experiment before you download it, and explains the results in a workflow you can inspect.

05YOUR FIRST FIVE MINUTES

Bring a file.
Leave with a plan.

DataForge is a Python package. Install it once, launch the dashboard from a terminal, and open the local address it prints.

INSTALL THE DASHBOARDpython -m pip install "dataforge-sba[dashboard,visualization]"
START THE DASHBOARDdataforge-sba dashboard

Windows: if the command isn’t recognized, close and reopen your terminal after installation.

06LOCAL BY DESIGN

Your data stays
your data.

DataForge’s dashboard runs on your own computer. It doesn’t send your dataset to DataForge or an external service, and it doesn’t overwrite the original file.

Read the source on GitHub ↗
⌂Local dashboardOpens on your computer at 127.0.0.1.ON DEVICE
◫Original stays safeCleaning happens in the session; you can reset.REVERSIBLE
↗You control the notebookDownloaded code runs when you choose in Jupyter.YOUR CALL

The dashboard allows files up to 25 MB. Uploaded files are stored in the local .dataforge folder for your session. Remove uploads in the dashboard when done. See the README for cleanup details and safe handling tips.
